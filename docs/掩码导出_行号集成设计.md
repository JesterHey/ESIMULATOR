# 集成 verilog_parser 到 dfg_linearity_corrector.py 的设计说明

## 目标
- 在每个 bind 导出的 JSON 中，为 dest 和 sources 增加其在原 Verilog 文件中的行号（如有）。
- 若为 DFG 中间变量或无法定位，行号为 None 或 0。

## 步骤
1. 在 CorrectedLinearityAnalyzer 初始化时，允许传入 verilog_file 路径。
2. 若传入 verilog_file，则用 verilog_parser 解析一次，得到 signal->line_number 的 dict。
3. 在 _build_bind_payload 阶段：
   - dest_location: 查找 dest 的行号（dict.get(dest, None)）。
   - source_locations: 查找 sources 每个信号的行号。
   - 若找不到，返回 None 或 0。
   - payload 增加 dest_location, source_locations 字段。
4. CLI 层支持 --verilog-file 参数，传递到 analyzer。

## 兼容性
- 不影响原有分析流程。
- 若未指定 verilog_file，相关字段为 None。

## 代码位置
- verilog_parser: esimulator/utils/verilog_parser.py
- 主集成点: src/analyzers/dfg_linearity_corrector.py (CorrectedLinearityAnalyzer)
- CLI: esimulator/cli/analyze_command.py, batch_command.py, compare_command.py

## 示例
{
  "dest": "alu.acc",
  "dest_location": 42,
  "sources": ["alu.data", "alu.cma"],
  "source_locations": [17, 23],
  ...
}

## 备注
- DFG/Verilog 命名需一致，若有前缀（如 alu.），verilog_parser 需支持。
- 未来可扩展为支持多模块、别名等。
