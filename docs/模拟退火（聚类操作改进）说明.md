# 模拟退火（Bind/Workset 聚类改进）说明

本文总结 SA 在 Bind/Workset 级的邻域与权重改造，目标是在不改变既有线性标记逻辑的前提下，把 concat/partselect 納入可掩码单元，并优先优化“模块数量 C 与接口 IFACE”。

## 1) 邻域操作

- flip：对某个 bind 的某个 workset 掩码位执行 1↔0 翻转。
- grow：在 `fusable_adj` 的线性簇边界外扩一层（若不触发分支约束）。
- shrink：对线性簇进行收缩，减少簇规模以降低接口。

说明：`bind_has_branch` 为真时，限制跨分支聚类；聚类只在同 bind 内进行。

## 2) 成本与权重（示例）

度量：L（线性数）、E（非线性数）、C（近似模块数/线性簇数）、IFACE（跨域/跨簇接口）。

成本：

```text
Area = a1*L − a2*E
Delay = d1*C
Power = p1*L
Interface = i1*IFACE
Total = wi*Area + wz*Delay + w3*Power + wa*Interface
```text

若要“优先考虑模块数量和接口”，可提高 `wz`、`wa`，并适当增加 `a2` 抑制无效线性扩张。

## 3) 权重与配置

示例（ONN/接口优先）：

```text
wi=0.7, wz=1.3, w3=0.3, wa=1.4
a1=0.6, a2=1.2, d1=1.2, p1=0.3, i1=0.8
```

## 4) 输出

`results/*_bindmask_sa_best.json` 中包含：

- best_total_cost 与各项分解（area/delay/power/interface）
- L/E/C/IFACE 度量统计
- 每个 bind 的最优 `workset_mask`

## 5) 提示

- concat/partselect 已纳入可掩码 workset，有利于 ONN 线性映射。
- grow/shrink 会参考 `fusable_adj`，以避免跨越不可融合边界。
- 可视化与 AMS 生成不依赖 SA，可单独运行；但若已有 SA 结果，AMS 生成器会按最优掩码生成包装与连接。
